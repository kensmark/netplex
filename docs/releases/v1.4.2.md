## NetPlex 1.4.2 — simpler Studio module controls

- Select a home module to reveal its trash icon directly in the module list.
- Delete modules without scrolling through their settings. Undo, redo, save and cancel continue to work.
- Remove the global Add preset category selector. Add a category, then use **Brug færdig kategori** inside its settings.
- Remove sections and Side by Side from Studio. Older layouts display their categories as ordinary modules in the same order, preserving IDs and filters. Saved layouts are only updated when you choose **Gem design**.
- Include NetPlex's MIT licence in the packaged application.

Validation: TypeScript/source checks, 39 backend/design tests and five isolated Windows UI flows, including legacy-layout preservation, deletion, keyboard access, undo/redo, saving and cancelling.
