## NetPlex 1.4.1 for Windows x64

The first packaged GitHub release of NetPlex: a customizable Windows client for your own Plex libraries.

### Install

Download **NetPlex-Setup-1.4.1.exe**, run the installer, and open NetPlex from the desktop or Start menu. Sign in with your own Plex account. The native player is included; no command files, Node.js or separate player installation are needed.

### Included

- Combined libraries from selected Plex servers, duplicate matching and source selection.
- Native original-quality playback with local audio/subtitle handling and Plex progress sync.
- Customizable home modules, metadata filters, sections and shared poster/landscape cards.
- Four included themes, personal themes and separate theme/layout JSON import/export.
- Direct header search with Ctrl+K and local Film/Serier search.
- Seven card-size steps, full-width rows, stable progress-bar spacing and wrapping carousel navigation.
- Full-screen controls that hide after inactivity.

The UI currently uses Danish labels. Normal Plex access and an available server are required. This installer contains no films, credentials or personal layouts. It is unsigned; Windows may show an unknown-publisher prompt. Original-quality playback requires sufficient network bandwidth and local decoding support. Multipart media and automatic updates are not supported yet.

`SHA256.txt` provides the installer checksum. Install over an existing NetPlex installation to keep your login and saved design.

Validation: TypeScript and source checks, 39 backend/design tests, 8 desktop tests, four isolated Windows UI scenarios, package and fresh-profile installation checks. Layouts were additionally checked with simulated 4K viewports at 100%, 150% and 200% scaling.
