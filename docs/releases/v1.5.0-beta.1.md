## NetPlex 1.5.0 beta 1 — macOS preview

This release adds a first macOS desktop build alongside Windows and removes the AI-placeholder screenshots and raster demo artwork from the project.

### Downloads

- **Windows x64:** `NetPlex-Setup-1.5.0-beta.1.exe` — run the installer.
- **Apple Silicon Mac:** `NetPlex-1.5.0-beta.1-macOS-arm64.dmg`.
- **Intel Mac:** `NetPlex-1.5.0-beta.1-macOS-x64.dmg`.

On macOS 14 Sonoma or newer, open the DMG, drag NetPlex into Applications, then open it and sign in with your own Plex account. The native player is included; Node.js, Homebrew and a separate player installation are not required.

The Mac preview is ad-hoc signed, not Apple Developer ID signed or notarized. macOS may block the first launch. For a download you trust, use System Settings → Privacy & Security → Open Anyway after the blocked launch. The Windows installer is also unsigned.

### macOS playback

Browsing, Studio, multiple Plex servers, themes and layouts use the shared NetPlex interface. On macOS, video opens in a separate **NetPlex Player** window with native playback controls. The NetPlex window can also control pause, seek, audio, subtitles and full screen. Closing the video window stops the session and returns to NetPlex; progress is saved to Plex. Windows retains its embedded player.

The included players are pinned and SHA-256 checked. Playback uses original quality and requires adequate network bandwidth and codec support on your computer. This is the first Mac preview: automated builds, clean-profile app launches and codec/IPC tests run on native Apple Silicon and Intel macOS runners, but viewing/audio and Gatekeeper behavior still need a manual check on the recipient's Mac.

The login and server-selection screen now uses the owner-supplied Akira, Dune and Godzilla Minus One posters.

### Studio improvements

- Select a module to show its trash icon. Delete, undo, redo, save and cancel work together.
- Preset categories are available inside the selected category's settings rather than at the top of Studio.
- Section/Side by Side editing is removed. Existing sections display their categories under one another without dropping their filters or saved titles.

No films, personal library images, Plex tokens or personal designs are included. `SHA256SUMS.txt` provides checksums for the installers. Existing published releases have not been replaced.
