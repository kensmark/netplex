# NetPlex assets

The application icon is drawn by `desktop/scripts/icon.mjs`; the web icon is an SVG. No AI-generated promotional screenshots or raster demo artwork are included in the current repository.

The login/server-selection screen uses the Akira, Dune and Godzilla Minus One posters supplied by the project owner, in `public/assets/login/`. These film posters retain their respective copyright notices and are not covered by the NetPlex source-code MIT license.

The optional demo uses fictional titles and CSS illustrations in `public/demo.js` and `public/styles.css`. These demonstrate layouts without exposing a real Plex account or library. Connected libraries use artwork from their own Plex servers.

`public/assets/unbounded-latin.woff2` is Unbounded from `@fontsource-variable/unbounded`; its SIL Open Font License is in `public/assets/FONT-LICENSE.txt`.
